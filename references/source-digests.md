# Source Digests

Use this file as a provenance and intake map. It summarizes useful content already absorbed into this skill so future users do not need the original links or local files merely to design a general.

## Online Design Essays

- https://www.bilibili.com/opus/1107326926420181009, "风雨如晦（上）": large historical-card design set. Useful lessons: choose concrete historical anchors, let a rule describe a sequence instead of one static trait, and treat non-三国杀 card-game mechanics only as inspiration after translation.
- https://www.bilibili.com/opus/825088145580097537, "曹宪曹华等上半年设计汇总": major source for design发端, internal linkage, locked-skill categories, and naming/title practice. Key lesson: decide the creative origin first, then keep mechanical language subordinate to that origin.
- https://www.bilibili.com/opus/745737843276513317, "族吴苋与张芝的设计理念": source for clan design layers, hand-limit family language, sparse-record再创作, and the later shift toward lower reread cost. Key lesson: reduce dynamic text and deep self-looping unless the payoff is unmistakable.
- https://www.bilibili.com/opus/693405298689310759, "神孙权的设计历程与反思": source for design subjectivity, complexity cost, random skill pools, special-card burden, and wording normalization. Key lesson: borrowed mechanics can solve fit problems but consume player attention and reduce original design space.
- https://www.bilibili.com/opus/674737966604615718, "SP孟获的设计理念与隐喻": source for staged narrative, soft limits, mark removal tradeoffs, and global-listener loop cautions. Key lesson: removing marks may also remove memory, storage, and timing play; replace those functions with visible history or simpler windows.
- https://www.bilibili.com/opus/815130006444310569, "【WAHX】三国杀新概念全点评·序": source for mechanism-quality evaluation, not a list of mechanisms to import. Key lesson: evaluate new concepts by innovation, generality, and robustness; distinguish small concept expansions from structural rule updates.
- https://www.bilibili.com/opus/815206035717357571, "【WAHX】三国杀新概念全点评·一（锁定技）": source for technical-label usage. Key lesson: 锁定技、阵法技、君主技、宗族技 should be treated as technical labels that call rules or UI/framework meaning, not as loose flavor; 锁定技 should mark fully compulsory skills rather than half-locked clauses.
- https://www.bilibili.com/opus/819363083023548439, "【WAHX】三国杀新概念全点评·二（强制更改牌面信息）": source for evaluating forced card-identity changes, virtual existence of equipment/delayed tricks, result inversion, and non-card-resource conversion. Key lesson: changing underlying card information is expressive but rule-fragile; prefer self-contained scopes, direct effects, and explicit virtual-card handling over broad "视为" layers.
- https://www.bilibili.com/opus/817817023885082632, "【WAHX】三国杀新概念全点评·三（标记牌）": source for evaluating card markers, public/private zones, special cards, destroy/out-of-game handling, judgment-area storage, central zones, and ordered discard piles. Key lesson: stored real cards need ownership, visibility, return flow, and skill-loss handling; public or off-deck resources are powerful vocabulary but should not be added merely to shorten text.
- https://www.bilibili.com/opus/821182237875634210, "【WAHX】三国杀新概念全点评·四（猜测）": source for evaluating guessing, hidden-information use, system-only checks, random execution, divination, command/ticket-style physical randomizers, out-of-game elements, mini-games, and non-rules text. Key lesson: prediction and randomness work only when choices, probabilities, and results are auditable; online-only hidden checks, oversized random props, and off-game references should be low-priority unless the brief explicitly calls for them.
- https://www.bilibili.com/opus/822237988083728437, "【WAHX】三国杀新概念全点评·五（作废）": source for evaluating declaration-time cancellation, resolution termination, and forced phase/turn ending. Key lesson: 作废 is safe only at a very early declaration timing; later termination needs explicit one-layer scope and cleanup, while forced ending should finish current resolution first.
- https://www.bilibili.com/opus/823255564635078744, "【WAHX】三国杀新概念全点评·六（标记）": source for evaluating named marks, markerless cross-turn memory, hand-card labels, revealed/hidden hand states, connected cards, packaged values, and declared variables. Key lesson: marks are useful memory aids but easy to overuse; cross-turn memory needs visible support, and custom gauges should not be introduced when an ordinary mark or temporary X is enough.
- https://www.bilibili.com/opus/824102807052222518, "【WAHX】三国杀新概念全点评·七（属性伤害）": source for evaluating attribute damage, special damage subtypes, fake damage records, extra card labels, Yingbian-like conditions, divination encapsulation, and enchantment-like skill attachment. Key lesson: splitting a base concept works when each subtype has distinct support and a preserved baseline; keyword encapsulation should be avoided when players must expand hidden skill text to understand it.
- https://www.bilibili.com/opus/824454809686900772, "【WAHX】三国杀新概念全点评·八（实体性操作）": source for evaluating physical orientation operations, turn/phase manipulation, seat swaps, and rehearsal/rollback concepts. Key lesson: physical state needs unique visual cues and readable components; turn-flow changes are powerful and environment-sensitive, while rollback-style concepts are usually too burdensome for normal generals.
- https://www.bilibili.com/opus/824885242719371398, "【WAHX】三国杀新概念全点评·九（重铸）": source for evaluating recast as dead-card recycling and later extensions to multiple cards, other players' cards, and non-card objects. Key lesson: 重铸 is excellent as a small support operation, but extended uses must define draw count, drawer, object type, and whether the operation is sequential.
- https://www.bilibili.com/opus/825219782013878296, "【WAHX】三国杀新概念全点评·十（拼点）": source for evaluating pindian, multi-player pindian, 逐鹿, team/opposed pindian, 锻造, 谋弈, and 议事. Key lesson: pindian works because it turns points into a visible contest with card choice; multi-player or psychological variants must preserve agency, define ties/card ownership, and avoid becoming disguised randomness or identity math.
- https://www.bilibili.com/opus/828057372414967825, "【WAHX】三国杀新概念全点评·十一（限定技、觉醒技）": source for evaluating limited skills, awakening, obsolete physical markers, delayed transformation labels, repeatable limited skills, skill reset/set-as-used, global counts, charge skills, round/deck-cycle limits, mission skills, and fate-line structures. Key lesson: one-shot, awakening, and task labels carry presentation weight; use them for real decisive moments, define count ownership/reset behavior, and keep task success/failure ordering stable.
- https://www.bilibili.com/opus/834003110400622664, "【WAHX】三国杀新概念全点评·十二（共计、分配）": source for evaluating total distribution, new-style allocation, refusal, forced activation, reset-option skills, and 枭雄技. Key lesson: allocation and choice-control mechanics are powerful because they reshape agency; define totals, bounds, simultaneity, refusal results, forced choices, and option-memory before using them.
- https://www.bilibili.com/opus/840842708369014806, "【WAHX】三国杀新概念全点评·十四（修改角色）": source for evaluating modified damage source, modified card user, full control, and light control. Key lesson: reassigning responsibility is expressive but rule-fragile and socially hostile; prefer bounded redirection or light forced actions, and define later trigger ownership when blame or credit changes.
- https://www.bilibili.com/opus/841935949368655905, "【WAHX】三国杀新概念全点评·十五（移动、置入、置于手上）": source for evaluating object movement, put-into operations, hand-area movement, 合纵, and 赠予. Key lesson: use exact movement only when the route or destination matters; otherwise ordinary gain/give/discard wording is clearer, while coalition or gift mechanics must preserve mode assumptions and consent around negative cards.
- https://www.bilibili.com/opus/853053991883374711, "【WAHX】三国杀新概念全点评·十六（羁绊）": source for evaluating named bonds, 珠联璧合, clan bonds, 金兰/同心-style relationships, formation relationships, and formation summons. Key lesson: relationship mechanics work best when partner selection or seat geometry is controllable; random identity designs should not rely on low-probability named easter eggs.

## Intake Rule For Future Sources

When adding a new source, preserve only reusable design knowledge:

- design principle;
- mechanism definition and safe usage;
- package/mode scope if relevant;
- one short example or naming pattern;
- caution that prevents bad loops, excessive marks, or survival-card abuse.

Do not store raw articles, full card tables, code paths, or code-level notes unless the user explicitly asks for a separate coding skill.
